# Gittrae — AI x 经济 · 题三「数据洞察官」

从描述统计到文字解读的自动洞察管线：输入 CSV → 输出统计量 + 图表 + 文字解读 + 报告。

## 项目结构

```
├── src/        清洗 / 统计引擎 / 图表 / 文字解读 源代码
├── reports/    分析报告（Markdown / HTML）
├── output/     清洗数据、统计 JSON、图表等成果物（入库）
└── data_raw/   原始数据包（不入库，仅本地存放）
```

## 数据组

| 数据组 | 分析单位 | 说明 |
|---|---|---|
| D1 居民收支（国家统计局） | 31 省 | 收入/支出/耐用品，2020–2024 |
| D2 上市公司财务（东方财富） | A 股公司 | FY2025 全样本 5227 家 + 8 行业教学样本 270 家 |
| D3 汽车销量（盖世 / 乘联会） | 车企 | 2025-09 ~ 2026-08 月度榜单 |

## 统计口径约定（对齐命题方真值）

- 标准差：样本标准差 `ddof=1`
- 直方图：10 个等宽箱
- 相关：Pearson，成对删除缺失
- 异常值：IQR 规则（Q1−1.5·IQR / Q3+1.5·IQR），含异常个体名单
- 偏度 / 峰度：pandas 默认（Fisher-Pearson 修正 / 超额峰度）
- 数值精度：全部保留 6 位小数

## 协作约定

- 原始数据包不入库（见 `.gitignore`），本地放置于 `data_raw/`
- 提交信息格式：`类型(阶段): 说明`，如 `feat(m1): D1 清洗脚本对齐 manifest`
- 数据事实与模型推断在解读中分区标注，不混淆
