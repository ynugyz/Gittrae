# T3 数据洞察官 · Gittrae

把经济数据转换为可计算、可解释、可回查原始记录的信息网络。

**当前交付：架构与角色交接基线、原始数据、团队核验样例。应用尚未开发，尚无可运行网页，也没有真实 API 测试通过记录。**

仓库：https://github.com/ynugyz/Gittrae

## 1. 从这里开始

1. 在自己的电脑克隆仓库，打开仓库根目录；本项目不依赖创建者的本机路径。
2. 阅读 [共同上下文](handoff/00_共同上下文.md)、[公共接口](handoff/01_公共接口.md)、[协作规则](handoff/02_协作与提交规则.md)。
3. 按下表领取角色，将对应 `START_HERE.md` 的内容发送给自己的智能体，并让其读取文件所列资料。
4. 首轮只核对职责与接口，按六项格式答复；**不启动业务开发、不安装依赖、不切分支、不提交推送**。

|---|---|---|

## 2. 已确定的产品

- 三名开发、一名独立审计、一个总控对话；正式开发以 150 分钟为目标。
- 本地网页支持居民收支、企业财务、汽车销量三类 CSV。
- 自动统计均值、中位数、样本标准差、分布、相关性，展示直方图、散点图、箱线图。
- 信息网络连接来源、数据集、指标、分析范围、计算和发现；点击数字回查参与计算的原始记录。
- 真实 DeepSeek AI 解读属于最终硬验收；事实与 AI 解读分区，明确相关不等于因果。
- 支持本地项目文件保存恢复。数值、来源和分析范围以确定性计算为准。

技术方案：React、TypeScript、Vite、Papa Parse、ECharts、本机 Node 模型代理。人员3在开发开始时锁定依赖和启动方式；本交接基线没有安装这些依赖。
