从仓库根目录复现：

```powershell
$env:PYTHONUTF8 = '1'
py -3 acceptance/reports/verify_reference.py
```

其他平台可使用 `python3 acceptance/reports/verify_reference.py`。退出码0表示本脚本的资料与独立参考检查通过；不表示应用验收通过。命令会覆盖本目录的参考JSON，更新时间和脚本SHA，原始CSV与固定样例保持只读。脚本验证固定基线；若团队更新数据或契约，须先明确新受测commit再更新审计材料，不得通过修改固定预期掩盖失败。

参考记录ID是该输入文件内CSV解析后数据记录序号的字符串，从1开始、计入空记录；它不是未来产品的recordId或analysisId。真实数据结果以输入文件路径和SHA定位，字段位置从0开始。缺失值不计为零，数字是计算精度，未为显示舍入。财务参考未筛选行业；D1为省级等权统计；D3仅为当月Top50榜单。

统计约定：样本标准差分母n−1，Type 7四分位，Pearson成对删除缺失，10等宽箱、左闭右开且最后箱含右端点，常量范围扩展±0.5，须线为1.5IQR界限内的实际观测点。全缺失、单值、常量返回相应null或空分布。固定样例数值容差1e−9；真实数据对照容差为max(1e−6, abs(reference)×1e−9)，计数、空值和引用位置精确比较。
