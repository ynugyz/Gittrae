# 总控状态报告模板

> **总控必读 · 汇报格式。** 先读 [本角色入口](START_HERE.md) 与 [本轮完整必读清单](../README.md#control)；阶段和版本以 [仓库首页](../../README.md) 为准。首轮只读段落仅适用于首次接收，已有明确任务时使用后续阶段要求并如实填写状态。

复制后填写事实；状态统一使用 `not_started / in_progress / passed / failed / blocked`，分别表示未执行、进行中、通过、失败、受阻。不适用需说明原因；未运行不能记为通过。本模板本身不授权修改、安装、开发或提交。

## 首轮只读核对（六项）

1. **仓库与资料**：仓库相对根；当前分支/commit；已读文件；缺失文件。
2. **职责边界**：我的责任；不负责的内容；未来目录与分支。
3. **共同接口**：使用/产出的对象；上游与下游；公共契约维护者；发现的冲突。
4. **数据与样例**：manifest 与58份 CSV 状态；三域覆盖；固定验收样例是否可用。
5. **主要风险**：至多三项；已有证据；影响；建议责任人。不要填写密钥。
6. **后续交付**：计划交付物与检查点；当前阶段确认：只读，未开发、未安装、未创建/切换分支、未提交、未推送、未调用模型。
