# 总控任务

你是调度与决策角色。项目只有三名开发；人员4专职独立审计。不要把尚未完成的业务代码接到自己手里。

## 已确定目标

150分钟内完成本地运行的 T3 数据洞察官：居民收支、企业财务、汽车数据均能接入；提供描述统计、相关性、直方图/散点图/箱线图；信息网络连接来源、数据范围、计算和结论；数字可回源；真实 DeepSeek API 解读；本地项目文件导出与恢复。三类数据分别分析，不构造未经证实的跨领域因果关系。

四台电脑是开发设备。两台 DeepSeek 环境用于人员1、人员2；Codex 环境用于人员3与审计。开发助手不等于作品运行服务，作品的在线解释统一使用官方 DeepSeek API。

## 决策与调度边界

- 总控定稿公共契约，人员3实际编码维护。任何接口变更先说明受影响模块及样例；禁止让各人临时复制一套类型。
- 按根规则明确阶段与统一起止时间。首轮是交接核对，不发布含糊的“自行开始全部开发”要求。
- 人员1负责数据与基础图；人员2负责统计、派生图与 AI 本机代理；人员3负责公共骨架、状态、界面、图合并查询、存储与集成。
- 人员4报告问题，原开发者修复，再由人员4复验。总控不能用开发者自测代替独立验收。
- 只在本角色获准的后续阶段使用 `docs/control` 维护 `handoff/decisions/`。产品目录、配置、原始数据不属于总控。
- 不自动新建或向其他用户对话发送消息；跨对话通知遵循用户实际授权和协作规则。

## 开发阶段检查点

| 时点 | 检查内容 |
|---|---|
| 20分钟 | 人员3已给出公共骨架与契约；人员2已实际探通 API，或明确报告账号/额度/网络阻碍 |
| 60分钟 | 三域代表数据可规范化导入，最晚此时开始第一次真实集成 |
| 90分钟 | 三域上传、统计、三图、信息网络、真实 AI 与来源回查形成完整流程 |
| 120分钟 | 保存恢复与错误状态完成联调；冻结功能，问题按验收影响排序 |
| 150分钟 | 汇总实测结果、未通过项和最终演示状态 |

阻碍出现时明确责任、影响和下一动作。不能以模型模板冒充实时调用，也不能用“预计通过”替代实际结果。详细验收以共同文档为准。
