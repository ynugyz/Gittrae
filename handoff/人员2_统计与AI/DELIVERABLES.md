# 人员2应交成果

> **人员2必读 · 交付要求。** 先读 [本角色入口](START_HERE.md) 与 [本轮完整必读清单](../README.md#person2)；阶段和版本以 [仓库首页](../../README.md) 为准。首轮只读段落仅适用于首次接收，已有明确任务时使用后续阶段要求并如实填写状态。

首轮只交 [只读状态报告](STATUS_TEMPLATE.md)，不安装依赖、不尝试读取密钥、不发起收费 API 请求、不开始编码。

开发阶段应交：

| 成果 | 最低要求 |
|---|---|
| `src/analysis/` | 统计、三图数据、有效样本与来源记录、派生图 |
| `server/` | 真实 DeepSeek 本机代理及明确的失败状态 |
| 计算验证 | 固定手算样例、三域真实样例、缺失/常量/样本不足检查 |
| AI 验证 | 三个数据域各至少一次当前页面触发的真实成功调用，引用与分析编号匹配 |
| 脱敏证据 | 调用时间、实际模型、成功/失败状态、对应分析编号；不含密钥 |
| 交接说明 | 服务如何启动和配置、界面如何调用、超时/旧结果如何处理、遗留问题 |

统计证据至少覆盖一个结果从数字到公式、输入记录和原始来源的完整路径。实时调用失败必须单独列为未通过，不能用模板兜底后标为全部完成。

向人员3交服务和分析接口，向人员4交可复验步骤及预期结果。代码只提交 `dev/analysis-ai`，不要自行合入 `main`；后续提交与推送遵循根规则。
