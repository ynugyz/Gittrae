# 人员2任务：统计、派生图与 AI

> **人员2必读 · 职责。** 先读 [本角色入口](START_HERE.md) 与 [本轮完整必读清单](../README.md#person2)；阶段和版本以 [仓库首页](../../README.md) 为准。首轮只读段落仅适用于首次接收，已有明确任务时使用后续阶段要求并如实填写状态。

## 职责与目录

明确进入开发阶段后，在 `dev/analysis-ai` 的 `src/analysis/`、`server/` 工作。使用人员3维护的 `AnalysisRequest`、`AnalysisResult`、`GraphFragment`、`Insight` 等共同契约；需要真实数据时读取人员1输出，不重新解析原始 CSV。

## 确定性分析

- 对居民、财务和汽车的统一数据完成均值、中位数、标准差、分布与相关性；提供直方图、散点图和箱线图数据。
- 标准差、分位数、有效样本筛选、百分比等口径严格执行公共接口与验收文档，不与图表库各算一遍。
- 缺失值、样本不足、常量列及无效数值需显式处理；记录有效数量、排除数量和原因，不能输出伪造的零或无说明的 NaN。
- 每次分析绑定数据版本、筛选范围和分析编号；相关性仅使用配对有效记录，不能默认混合不同年份或口径。
- 保存计算方法及输入来源引用，生成数据切片、计算和结果之间的派生图关系。统计值由程序计算，模型不参与算数。

## 真实 AI 服务

- **开发前20分钟优先完成一次真实 DeepSeek API 调用**。密钥、额度或网络未就绪时立即如实报告具体阻碍，同时继续独立统计开发。
- 本机 Node 代理由你实现；人员3负责页面调用和状态展示。端点与请求响应结构以公共接口为准。
- 密钥只在本机服务端配置，不写入源码、浏览器、日志、审计截图或项目文件；不要求他人在聊天中粘贴密钥。
- 模型接收当前已算出的统计结果、范围、单位和必要背景，产生简短解释并引用存在的结果编号。不存在的引用不能作为有效结论展示。
- 区分事实与推测，明确相关不等于因果；不把财务数据描述为推荐买卖，不把榜单样本当全部市场。
- 返回状态应让人员3区分实时成功、失败、取消与旧结果；筛选变化后旧请求不得覆盖新分析。
- 模板、模拟和已保存的解释可用于开发，但必须标注其来源，不能算真实 API 验收通过。

## 边界与节点

不修改 CSV、公共类型、根依赖或前端状态。依赖/接口变更交人员3统一处理。20分钟 API 探通，最晚60分钟进入真实集成，90分钟三域统计、三图数据、真实解释与回源联动可用；120分钟前修复错误与恢复相关问题，最后30分钟接受独立复验。为审计提供脱敏调用证据与可手算统计样例。
