# 总体验收标准

> **全员必读。** 产品硬验收与独立性要求；人员3开发自测不能替代人员4对集成版本的审计。 先核对 [仓库首页](../README.md)，并按 [交接必读总索引](README.md) 阅读本角色新增材料。

## 1. 交接包验收与产品验收分开

初始交付为架构、数据和角色资料；当前人员3已提供部分实现与开发自测，完整产品尚待集成。交接包检查只能证明资料齐全、路径有效、原始数据可核对、职责接口清晰；不能据此宣布T3产品通过。

交接包完成要求：58个原始CSV与manifest一致；五个角色各有START_HERE、TASK、DELIVERABLES、STATUS_TEMPLATE；公共接口只有一份；自建参考答案明确标注；其他电脑能够按相对路径领取任务。

产品验收由人员4独立执行，详细矩阵见 [acceptance/cases.md](../acceptance/cases.md)。矩阵中的初始状态不自动随开发自测变更；独立产品结论必须另附实际受测commit及证据。

## 2. 产品硬验收

1. **三类数据可用**：居民收支、企业财务、汽车销量分别完成导入、统计、直方图/散点图/箱线图、真实AI解释和来源回查；全部58个原始CSV完成导入检查。
2. **统计正确**：均值、中位数、样本标准差、分布、Pearson相关按统一口径计算；缺失、常量和样本不足有明确行为；先过手算小样例，再独立核对真实样例。
3. **信息网络可操作**：指标可以发起分析，发现可以追查到计算、范围与原始位置；图不是一份与实际计算脱节的装饰。
4. **回源真实**：每域至少抽查三处，跨文件转换后的值仍能对应原始CSV数据记录和列；计算范围与解释引用一致。
5. **真实模型调用**：每域至少一次实际DeepSeek官方API成功；不存在的结果引用被拒绝。模板、模拟、缓存不能替代此项。
6. **范围同步**：切换年份、月份、行业或指标后，图、结果、解释和来源属于同一分析；旧异步响应不能覆盖新结果。
7. **保存恢复**：本地项目恢复后稳定ID、数据版本和引用不变，历史解读时间可见；不自动重新调用模型；导出无密钥。
8. **可在主机运行**：完整财务表可操作，图谱不创建上万单元格节点；启动说明适用于仓库任意克隆位置。

## 3. 数据口径与诚实表达

- 居民：全体/城镇/农村分开；同年省份横截面为默认；省份简单均值不称全国人均。
- 财务：股票代码为文本；原始数据含混合市场，沪深代码筛选规则和排除数量可见；缺失不补零、负利润保留。
- 汽车：车企、车型、CPCA口径分开；Top50非全市场；有问题的原始环比列禁用于统计结论。
- AI：数据事实与模型解读分别展示，明确“相关不等于因果”；模型不能补造外部事实或重新计算数字。
- 原包没有官方统计真值和清洗脚本实物。团队样例、独立复算与官方gold必须区分。

## 4. 审计、修复、签收

人员4记录“复现步骤—预期—实际—证据—责任人”，对应开发者修复后由人员4复验。总控确认范围和未完成项，人员3负责集成与运行交付。只有三名开发，审计人员不兼任第四名业务开发。

状态统一使用 `not_started / in_progress / passed / failed / blocked`。in_progress表示已开始但尚无最终结论；未执行不能记passed；外部模型接口未就绪记blocked，不能判定整体通过。所有结论绑定受测commit和数据SHA，避免拿旧证据验收新代码。

每名人员交接必须给出：成果路径、commit、实际通过的检查、遗留问题、下一角色接手事项。最后30分钟用于修复与复验，不再扩展产品范围。
