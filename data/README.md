## 2. 从仓库根目录读取

- 完整文件清单：`data/manifest.json`。其中 `relativePath` 均相对仓库根目录；不要加本机绝对路径。
- `dataVersion` 标识这份原始数据基线；单文件用 `sha256` 核对。包指纹按 manifest 中说明的路径与哈希组合方法生成。
- `columns` 是真实 CSV 表头，保留空表头；`parsedRecordCount` 不含表头。
- `adapterType` 是预期解析路径标签，不表示解析器已经实现：`nbs-regional-wide`、`eastmoney-financial`、`gasgoo-ranking`、`cpca-table`。
- 清洗或转换应创建派生数据并保留来源映射，不覆盖 `data/raw/`。

## 3. CSV 记录位置

CSV 必须按标准引号、分隔符与换行规则解析。**`SourceRef.recordIndex` 从 1 开始，不含表头；`SourceRef.columnIndex` 从 0 开始**。表头是单独的一条 CSV 记录。CSV 解析出的空记录也占据原始记录位置；清洗时可以过滤空记录，但不能重新编号来源位置。`parsedRecordCount` 是数据记录数，`physicalLineCount` 是文本物理行数，两者不能混用。带引号的字段可以跨物理行，一条记录未必等于一行。

本批文件实际没有跨行记录：物理行数等于数据记录数加表头 1 行，但通用上传器仍须支持跨行字段。来源定位至少保留文件身份/版本、数据记录编号、字段标识或原列序号；不要把清洗后行号当成原始行号。D1 的空表头首列应显式识别为地区，并同时保留原表头。

## 4. 来源与解读边界

来源 URL 来自随包说明；本次核验范围是本地文件，不代表站点当前可用性或逐项真实性已重新联网核查。随包记录的采集日期为 2026-10-14。

- D1：[国家统计局国家数据](https://data.stats.gov.cn/)，[统计发布入口](https://www.stats.gov.cn/sj/zxfbhjd/)。详见 [居民收支说明](sources/D1_居民收支_来源与字段.md)。省级人均指标的等权平均不等于人口加权的全国人均值。
- D2：[东方财富业绩报表](https://data.eastmoney.com/bbsj/)。详见 [企业财务说明](sources/D2_企业财务_来源与字段.md)。原始文件混合市场；缺失行业要显式保留或记录剔除理由。
- D3：[盖世汽车榜单](https://i.gasgoo.com/data/ranking)、[乘联会数据](https://data.cpcadata.com/)。详见 [汽车行业说明](sources/D3_汽车行业_来源与字段.md)。榜单是 Top50 截尾样本；原始环比列不直接用于分析；总量、占比与榜单不是同一种统计范围。

[题目原文与当前交付差异](sources/T3_题目要求.md) 将官方要求与本地实际文件分开说明。相关不等于因果；缺失值不等于零；实际测得的统计结果才能进入分析报告。
