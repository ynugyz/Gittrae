# D3 汽车行业：来源、字段与已知问题

## 1. 来源与实际文件

- [盖世汽车销量榜单](https://i.gasgoo.com/data/ranking)：车企、车型月榜。
- [乘联会数据](https://data.cpcadata.com/)：乘用车总量、结构和厂商排名表。
- 随包说明记录采集日期为 2026-10-14；本次未重新联网采集或验证站点。
- 读取目录：`data/raw/D3_行业与宏观_火山引擎等/`。目录名称保留原样，但实际文件来自盖世汽车和乘联会；不能称为已接入火山引擎数据服务。

共 37 份 CSV、1,352 条原始数据记录、72,526 字节：24 份盖世月榜（车企 12、车型 12，每份 50 条，共 1,200 条）与 13 份 CPCA 表（共 152 条）。

## 2. 榜单字段与范围

文件名 `GASGOO_rank_firm_YYYYMM.csv` / `GASGOO_rank_model_YYYYMM.csv`，覆盖 2025-09 至 2026-08。建议适配器 `gasgoo-ranking`。

| 字段模式 | 含义 | 处理要求 |
|---|---|---|
| 厂商 / 车型 | 本榜单对象 | 两种对象分开，不凭名称相似自动连接 |
| `2026-8` 等 | 当月销量，辆 | 文件月份与表头共同检查 |
| `8月同比` 等 | 同比百分比文本 | 去 `%` 后按百分点数存储，保留原值 |
| `8月环比` 等 | 源站标注的环比 | 有口径问题，原样保存但默认禁用于分析 |
| `2026-1到8` 等 | 指定年份起至该月的累计销量，辆 | 年份和月份随文件变化；不与当月值混用 |

每月是 Top50 截尾样本，榜单成员会变化。榜单销量和只能称“该月 Top50 合计”；份额只能称“榜单内份额”，不能称全市场份额。某对象未上榜不等于零销量。同比极端值可能受小基数影响，先保留并说明，不无依据删去。

源说明已指出环比列口径错误，原始样本也可见单月值相对累计值的异常关系。不要照抄“全部落在 -68% 至 -94%”这一描述：2026 年 1 月表中实际存在 0%。若确需重算环比，应使用同一对象相邻月份的单月销量；缺前月或前月为零时返回不可计算，并记录原因。

## 3. CPCA 表字段与范围

建议适配器 `cpca-table`，按文件与真实表头区分子类型。

| 文件组 | 表头/范围 | 单位与注意 |
|---|---|---|
| `CPCA_total_狭义乘用车_产量/批发/零售/出口.csv` | 月份、2025年、2026年；每表12行 | 按来源说明为万辆；四种统计口径分别保存 |
| `CPCA_fuel_整体市场.csv` | 月份、2025年、2026年；12行 | 来源说明称新能源乘用车销量，万辆；不能仅按“整体市场”文件名解释为全市场 |
| `CPCA_fuel_销量占比_ICE_NEV.csv` | 月份、NEV、ICE；12行 | 百分比，燃油/新能源结构 |
| `CPCA_fuel_销量占比_PHEV_BEV.csv` | 月份、PHEV、BEV；12行 | 百分比，新能源内部结构；分母与上表不同 |
| `CPCA_country.csv` | 年月、其他欧系/德系/日系/法系/美系/自主/韩系 | 国别系零售份额，百分比 |
| `CPCA_segment_轿车/SUV/MPV.csv` | 年月、对应级别列 | 各车型大类内部级别结构，百分比 |
| `CPCA_manrank_狭义乘用车_单月_批发.csv` | 厂商、2025年8月、2026年8月；10行 | 厂商排名，万辆；不是全厂商 |
| `CPCA_manrank_狭义乘用车_累计_批发.csv` | 厂商、2025年1—8月、2026年1—8月；10行 | 累计批发排名，万辆；与单月范围分开 |

年份列的后续月份可为空，不能补零；结构表中的年月在行值中，而总量表年份在列名中，解析方式不同。销量“辆”与“万辆”转换必须有明确转换记录；百分比与销量不能直接求和。原包没有提供厂商属性派生映射、清洗长表或统计真值，不自动沿用旧说明中关于自主/合资/外商独资的分组数量。
