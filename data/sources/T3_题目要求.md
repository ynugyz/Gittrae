## 1. 官方题目正文

题三　数据洞察官 —— 从描述统计到文字解读　★★★

对标：统计软件输出 ＋ 数据新闻

一句话背景：拿到一份数据，多数人既不会做描述统计，更不会把数字讲成结论。做一个“数据进去 → 统计 ＋ 图表 ＋ 一段人话解读”的工具，学习价值直接拉满。

输入数据（组委会提供）

· sample_datasets/：1—2 份样例数据集（如居民消费调查、企业财务）

· expected_stats.json：均值、中位数、分布、相关系数等标准答案（真值，供评委核验）

【数据包需求】需提供（样例数据集 ＋ 统计量真值；成本低）

合规提示：解读必须基于数据本身；结论与推断分开标注，不得越出数据下断言。

基础项（必做）

1. 读入 CSV，自动计算描述统计（均值 / 中位数 / 标准差 / 分布 / 相关）

2. 自动绘图（直方图 / 散点 / 箱线）

3. 生成“这组数据说明了什么”的文字解读，数字可点击回看来源

4. 给出“相关不等于因果”的提示

进阶项（加分）

· 简单回归与相关性分析

· 异常值检测

· 多组对比

· 导出分析报告

· 把“数据事实”与“模型推断”分区展示

验收锚点

· 统计量与标准答案偏差在容差内

· 文字解读不出现数据中没有的结论

· 至少一处明确提示“相关不等于因果”

起步提示词：「做一个数据解读网页：上传一份 CSV，自动算均值/中位数/分布/相关并画图，再生成一段“这组数据说明了什么”的文字解读，解读里的数字能点回去看来源，并提示相关不等于因果。」

## 2. 与本仓库实际交付的差异

- 题目要求样例 CSV 和 `expected_stats.json`；实际发放目录存在 58 份原始 CSV 及来源元数据，未找到官方清洗表、统计真值或复现脚本。
- 本仓库提供原始文件、逐文件指纹与真实结构清单，没有把缺失文件补造成“官方文件”。
- 开发者可生成独立参考计算与合成测试，但必须标为项目自建参考，不能冒充组委会标准答案。官方验收容差没有在上述正文中给出具体数值。
- 图网络是本项目的实现架构；真实 DeepSeek API 调用是本项目另行确定的交付要求。二者均不应误标为上述官方基础项原文。
